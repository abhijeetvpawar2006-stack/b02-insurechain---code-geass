# InsureChain — Code Geass

## Project Overview
InsureChain is an insurance claims management and verification platform developed for a hackathon.

## Features
- Insurance claim submission and tracking
- Policy verification
- Claim review and approval workflow
- SHA-256 audit-chain demonstration
- Supabase database integration (verification pending)

## Technologies Used
- HTML, CSS, JavaScript
- Supabase PostgreSQL
- Netlify
